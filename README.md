# doggo-legal

Public legal pages for the [Doggo](https://apps.apple.com/) iOS app, served as a static site via GitHub Pages.

Live URLs:

- Landing: https://pauliusos.github.io/doggo-legal/
- Privacy Policy: https://pauliusos.github.io/doggo-legal/privacy.html
- Terms of Use: https://pauliusos.github.io/doggo-legal/terms.html

These URLs are linked from the in-app Settings screen and from the Doggo listing in App Store Connect.

## Editing

Edit the `.html` files directly and commit to `main`. GitHub Pages rebuilds automatically.

When changing the privacy policy substantively, update the "Last updated" date at the top of `privacy.html`.
